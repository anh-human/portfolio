# ✨ Huu Anh Nguyen - Modern Developer Portfolio

A sleek, responsive, and high-performance portfolio website built with **Vue 3**, **Vite**, and **Tailwind CSS v4**. Featuring Material Design 3 aesthetics, smooth animations, and multi-language support.

## 🚀 Features

- 🎨 **Material Design 3**: Sophisticated color system with dynamic theme switching (Light/Dark).
- 🌓 **Dynamic Theme**: Smooth transitions between light and dark modes.
- 🎭 **Motion & Animations**: Interactive UI elements powered by `@vueuse/motion` and `Motion`.
- 🌍 **Multi-language Support**: Seamless switching between English and French.
- 📱 **Fully Responsive**: Optimized for all devices, from mobile phones to large desktops.
- 💎 **Glassmorphism**: Elegant frosted-glass navigation and modern UI components.
- 🚀 **Performance First**: Optimized with Vite for near-instant load times.

## 🛠️ Tech Stack

- **Framework:** [Vue 3](https://vuejs.org/) (Composition API)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide Vue Next](https://lucide.dev/)

- **Deployment:** [GitHub Pages](https://pages.github.com/)

## 📦 Getting Started

### Prerequisites

- Node.js (v20.19.0 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/anh-human/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```sh
   npm install
   ```

### Development

Run the development server:
```sh
npm run dev
```

### Build & Deploy

To create a production build:
```sh
npm run build
```

To deploy to GitHub Pages:
```sh
npm run deploy
```
